Texas Instruments LPC speech synthesizer.

Valadon’s *Bagman* arcade board paired the TMS5110 with a little ROM-driven state machine to feed it speech commands. [MAME’s Bagman board notes](https://github.com/mamedev/mame/blob/master/src/mame/valadon/bagman.cpp)
