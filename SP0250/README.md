# SP0250

> Parts of this README were generated using AI.

## General

<img src="SP0250.png" width="600" height="360">	

The voice calling out warnings in Sega’s *Astro Blaster* comes from an SP0250 on a dedicated speech board. The same arcade machine had a separate board for the other sound effects. [MAME’s Sega G80 hardware notes](https://github.com/mamedev/mame/blob/master/src/mame/sega/segag80r.cpp)
