# VRC6

> Parts of this README were generated using AI.



## General

Three Famicom games used this mapper. I pulled mine from a Japanese copy of *Madara*.

Konami put two pulse voices and a sawtooth voice in the cartridge mapper. You can hear all three in *Akumajō Densetsu*, the Japanese Famicom counterpart to *Castlevania III*. [NESdev VRC6 audio notes](https://www.nesdev.org/wiki/VRC6_audio)
