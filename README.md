
# Vintage Soundchip Collection

My personal collection of vintage sound and speech chips from the 1970s to the early 1990s. Browse by part number for chip photos, datasheets, service manuals, and notes for building your own circuits.

## Circuit projects

- **UM6526P1 PAL TIA / ESP32 (Rev. A)**. Prototype design with structural checks. [Schematic PDF](CO10444_TIA/TIA_UM6526P1_Schematic_RevA_EN.pdf) · [Project files and verification notes](CO10444_TIA/TIA_UM6526P1_RevA_EN/README.md)
- **POKEY / ESP32 (Rev. A)**. Document-reviewed prototype design. [Schematic PDF](CO12294_POKEY/POKEY_ESP32_RevA_EN/POKEY_ESP32_Schematic_RevA_EN.pdf) · [Project files and verification notes](CO12294_POKEY/POKEY_ESP32_RevA_EN/README.md)

Both projects still need hardware testing.
