# TMS3477

> Parts of this README were generated using AI.

## General

<img src="TMS3477.png" width="600" height="360">	

Texas Instruments voice recorder and playback chip.

Elektor used it for a solid-state voice recorder in 1989. A pair of 1-Mbit DRAM chips and the slowest sampling setting could stretch a recording to about two minutes. [Elektor voice recorder article](Elektor%5Bnonlinear.ir%5D%201989-07_text.pdf)
